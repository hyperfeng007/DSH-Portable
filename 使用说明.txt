  DeepSeek 智能体 —— 使用说明（一页纸）
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

【第一步】把整个 DSH-Portable 文件夹放到你想放的地方
   （U 盘、或 D 盘等本地磁盘都可以，路径尽量短、别带中文，如 D:\DSH）。

【第二步】双击「DeepseekHarness.exe」（鲸鱼图标的那个）。
   · 屏幕中间会出现一个小进度条，显示正在做什么、已经等了几秒。
   · 首次运行会自动安装一次（约 1~3 分钟，需联网），进度条会写
     "首次安装…"，装完自动进入；以后再点几秒就开。
   · 进度条走完，自动弹出「DeepSeek Harness」应用窗口
     （没有地址栏、没有标签，看起来就像独立软件；F11 全屏）。
   · 全程没有黑色命令行窗口。

【第三步】第一次使用，做两件事：
   ① 填密钥：界面里点「设置 / 模型」，粘贴 DeepSeek API Key
      （sk- 开头，到 platform.deepseek.com 的 API Keys 里创建）
   ② 选工作区：点「选择工作区」，选本文件夹里的 workspace 文件夹
      ★ 重要：选 workspace，智能体生成的文件才会跟它走

【第四步】选好工作区后，直接打字让智能体干活。

【第五步】用完：直接关掉应用窗口就行。
   · 后台的服务会在 1~2 秒内自动全部退出，不留任何进程。
   · （若在 U 盘）然后安全弹出 U 盘。
   电脑上不会留下任何东西（密钥、会话、设置都在本文件夹内）。

【公司网络 / 需要代理？】不用管。
   启动时会自动读取当前电脑的系统代理设置（Internet 选项 / PAC / 环境变量）
   并交给智能体使用；也会让它信任公司证书。
   想手动指定：在 dsh-home\.env 里写一行  HTTPS_PROXY=http://地址:端口

常见问题
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
· 双击 exe 提示"Windows 已保护你的电脑"？
    → 点「更多信息」→「仍要运行」即可。
      这是因为它没有买微软数字签名，属正常现象。

· 进度条走了很久（几分钟）还在"首次安装"？
    → 正在下载，网络慢时多等一会儿；失败会自动弹出原因。
      公司电脑请确认代理已开启（浏览器能上网即可）。

· 弹出了红色错误框？
    → 按提示看同目录下的 Start-DSH.log / dsh-web.log / npm-install.log，
      多数是网络问题；重试或双击 Update-DSH.bat 重装即可。

· 双击后提示"已在运行"？
    → 它已经开着了，会自动把窗口拉到前台；没看到窗口就等几秒再点。

· 怀疑还有东西在后台跑？
    → 双击 Stop-DSH.bat，一次清干净。

· 想全屏？→ 在应用窗口里按 F11

· 想升级到最新版？→ 先关掉窗口，再双击 Update-DSH.bat

· 忘记密钥？→ 到 platform.deepseek.com 重新创建一个

· 我的密钥和记录存在哪？安全吗？
    → 都在本文件夹（dsh-home）里，不会留在电脑系统里。

· 各文件是什么？
    DeepseekHarness.exe  主入口（双击即用）
    Install-DSH.bat      提前安装（可选，能看到安装过程）
    Update-DSH.bat       升级到最新版
    Stop-DSH.bat         强制停止所有相关进程
    DSH-Terminal.bat     命令行模式（高级用户）
    Start-DSH.ps1        启动脚本（exe 自动调用，不用管）
